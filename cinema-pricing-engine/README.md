# Cinema Pricing Engine

A simple cinema ticket pricing engine built using HTML, CSS and JavaScript.

## Features

- Silver, Gold and Recliner seat tiers
- Sold-out seat validation
- Multiple ticket booking
- Festival flat discount
- Member percentage discount with a maximum cap
- Per-ticket convenience fee
- GST calculation
- Exact two-decimal currency output
- Line-by-line bill breakdown
- Messy price-list import
- Case-insensitive duplicate detection
- Invalid, blank and negative price rejection
- Import report
